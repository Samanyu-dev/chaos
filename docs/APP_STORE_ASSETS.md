# 🏬 App Store Visual Assets & Storyboard Specification

This document details the screenshot guidelines, video storyboards, and marketing assets required for the App Store listing.

---

## 🎨 App Store Visual Style Guide
- **Color Palette**: Dark, neon-lit themes (midnight blues and magenta glows) to match Orbit's Tokyo Nights theme.
- **Typography**: Clean, bold sans-serif fonts (e.g. SF Pro or Outfit) overlaid on translucent glass panels.
- **Device Mockups**: High-fidelity iPhone device frames with minimal visual noise.

## 🎥 App Preview Video Storyboard (30 Seconds)

**Length**: 30 seconds  
**Tone**: Fast-paced, cinematic, energetic, synchronized to an upbeat electronic track.

| Time | Visual Scene | On-Screen Text Overlay | Sound Effect (PCM) |
| :--- | :--- | :--- | :--- |
| **0:00 - 0:05** | The Splash Screen breathes, then scales down to reveal the passcode authentication pad. Code `1997` is typed, unlocking the app. | **ENTER THE MATRIX** | High-frequency transition sweep. |
| **0:05 - 0:12** | Camera pans Shibuya map to the **Trip Planet** rotating. Tabs are clicked, zooming the camera. | **THE MAP IS THE OS** | High-frequency ticks on tab switches. |
| **0:12 - 0:18** | Friends tracker pins appear. An avatar is tapped, drawing neon trails. A meetup emoji floats up. | **TRACK USER TRAILS** | Sonar chimes on tap actions. |
| **0:18 - 0:24** | Switch filter to **Expenses**. Pinned geolocated bills (`💸`) reveal split balances. | **MAP SHARED BILLS** | Cash register feedback sound. |
| **0:24 - 0:30** | Neon roulette spinner rotates over Shibuya anomaly, decelerating to reveal results. | **EMBRACE THE CHAOS** | Decelerating chiptune clicks -> victory arpeggio. |
